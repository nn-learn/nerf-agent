# Agent V5：可信记忆治理

Agent V5 将现有“可提取、可合并、可召回”的 Memory 升级为可追溯、可纠正、可遗忘且不能越权影响心理支持决策的可信记忆系统。V5 不替换现有 Ollama 提取器或 BGE 候选召回，而是在写入、更新、召回和删除路径增加 host-owned 治理契约。

## V5.0：Memory Ledger

V5.0 已为原子记忆增加以下持久化字段：

- `source_type`：区分用户陈述、用户编辑、模型提取、外部工具、视觉观察和旧数据；
- `sensitivity`：区分普通、个人、健康敏感和危机敏感信息；
- `allowed_uses`：显式限定个性化、回答上下文、安全支持或聚合分析用途；
- `observed_at_ms`：记录系统何时观察到该主张；
- `valid_from_ms / valid_to_ms`：记录主张在现实世界中的有效区间；
- `derived_from_memory_ids`：记录摘要、归纳或其他派生记忆的来源链。

旧数据库会以 `LEGACY / GENERAL` 和最小兼容用途完成在线迁移。新派生记忆的父节点必须存在且属于同一用户，悬空引用和跨用户 lineage 会 fail-closed。`valid_to_ms` 到期的事实不再参与当前召回，但仍保留在可审计历史中；数据保留期限继续由 `expires_at_ms` 独立控制。用户编辑会被明确标记为 `USER_EDIT`，并刷新观测时间，而不是伪装成模型原始提取。

## 后续阶段

- V5.1：冲突、否定、撤回和可验证级联遗忘；
- V5.2：BGE 候选召回后的 Memory Use Policy 与敏感记忆安全门；
- V5.3：用户查看、确认、更正、暂停、导出和删除记忆；
- V5.4：过时记忆、反事实收益、跨用户泄漏和删除完整性评测；
- V5.5：仅在多跳时间/关系查询确有收益时引入轻量图记忆。

## 边界

Memory 只能提供带来源的候选背景，不能单独完成诊断、当前风险判断、Care Loop 目标确认或干预授权。工程测试证明数据契约和迁移行为，不证明临床有效性或生产合规。
